# Ticketing System (PHP & MySQL)
A web app where users submit support tickets and admins resolve them.

## The problem
Users needed a single place to report issues and track their progress.

## What it does
- Users register, log in and submit tickets
- Users track the status of their tickets
- Admins view, update and close tickets

## Built with
PHP, MySQL, HTML/CSS, JavaScript

## How to run it
1. Install XAMPP (or similar)
2. Import `database/schema.sql` into MySQL
3. Copy the files into your `htdocs` folder
4. Open `http://localhost/ticketing-system-php`

## What I learned
- Designing a relational database
- Handling user logins and roles
- Debugging PHP and SQL errors
